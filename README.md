# 📝 Prompt Engineering para Desarrollo Web (HTML & CSS)

Una guía visual y práctica para aprender a interactuar eficazmente con la
**Inteligencia Artificial**, diseñada específicamente para estudiantes que están
dando sus primeros pasos en la maquetación web.

## 🎯 Objetivo del Proyecto

El objetivo de este repositorio es enseñar las mejores prácticas de **Prompt
Engineering** aplicadas directamente al ecosistema Front End. A través de
comparaciones claras entre peticiones ineficientes (❌) y peticiones optimizadas
(✅), los alumnos aprenderán a solicitar código HTML semántico, accesible y
hojas de estilo CSS estructuradas.

Aprender a comunicarse con la IA es una habilidad fundamental para el desarrollo
moderno; un buen _prompt_ marca la diferencia entre recibir un código
desordenado y obtener una base sólida, accesible y escalable.

## 🚀 Qué aprenderán los alumnos

Al explorar este proyecto, los estudiantes podrán ver ejemplos prácticos de cómo
pedirle a la IA ayuda con:

- Creación de estructuras HTML5 semánticas (`<header>`, `<main>`, `<section>`,
  `<article>`).
- Aplicación de estilos CSS modernos para maquetación (Flexbox, Grid).
- Consideraciones de accesibilidad web (a11y) desde el primer momento.
- Explicación de conceptos teóricos complejos mediante analogías.
- División de tareas grandes (como maquetar un portafolio entero) en pasos
  pequeños y manejables.

## 🛠️ Tecnologías aplicadas en este repositorio

Este proyecto no solo enseña sobre IA, sino que su propio código fuente es un
ejemplo de buenas prácticas Front End:

- **HTML5 Semántico:** Estructura clara y accesible para lectores de pantalla.
- **CSS Moderno:** * Uso de *Custom Properties\* (variables) para mantener
  consistencia visual.
  - _CSS Nesting_ nativo para un código más limpio.
  - Soporte para _Dark Mode_ adaptado a las preferencias del sistema del
    usuario.
  - Uso de pseudo-clases avanzadas (`:is`, `:where`, `:has`) sin perder la
    simplicidad.
