Resumen: Prompt Engineering

Una guía para principiantes sobre cómo escribir prompts efectivos.

Sé específico, usa términos técnicos y aporta contexto

Centrar Elementos

❌ Evita preguntar: ¿Cómo centro algo?

✅ En su lugar, pregunta: ¿Cuál es la mejor manera de centrar un elemento div horizontal y verticalmente en una página web utilizando CSS moderno?

Explicar Conceptos

❌ Evita preguntar: Explica flexbox

✅ Especifica el lenguaje/tecnología y pide ejemplos: Explica el concepto flexbox de CSS e incluye dos ejemplos de código.

✅ Incluye contexto adicional como la audiencia y el estado del proyecto: Explícame el concepto flexbox de CSS como si fuera un desarrollador principiante que recién está aprendiendo. Proporciona un ejemplo de cómo puedo usar flexbox para alinear los elementos de una barra de navegación (navbar).

Crear Elementos

❌ Evita preguntar: ¿Cómo creo un formulario?

✅ En su lugar, pregunta: Crea la estructura HTML semántica y el CSS para un formulario de contacto accesible, que incluya etiquetas (labels) conectadas a sus campos para nombre, correo electrónico y un botón de envío.

Ejemplos de Componentes de Interfaz

❌ Evita preguntar: Muéstrame un ejemplo de una tarjeta

✅ En su lugar, pregunta: Por favor, crea el HTML y CSS de una tarjeta de perfil de usuario (User Profile Card). El diseño debe incluir una imagen circular, un nombre en negrita, la profesión debajo y un botón de "Contactar". Asegúrate de usar CSS Grid para la distribución interna y que sea responsivo.

Controlar la longitud y el formato de las respuestas

  • ✅ Buena práctica: Pedir pasos: Proporciona una breve explicación de 3 pasos sobre cómo importar y aplicar Google Fonts en una hoja de estilos CSS externa.
  • ✅ Buena práctica: Información en formato de tabla: Destaca las diferencias de uso principal entre CSS Grid y CSS Flexbox en un formato de tabla claro.
  • ✅ Buena práctica: Resumir con viñetas: Por favor, resume en 3 viñetas por qué es importante utilizar etiquetas HTML semánticas como <main> y <article> en lugar de agrupar todo en etiquetas <div>.
  • ✅ Buena práctica: Pedir los conceptos más importantes: Enumera los 5 conceptos más importantes de CSS que un maquetador principiante debe dominar antes de intentar traducir un diseño de Figma a código web.
  • ✅ Buena práctica: Resumir como diagrama de flujo: Usa un diagrama de flujo simple para explicar en qué orden aplica el navegador los estilos CSS según el modelo de cascada.
  • ✅ Buena práctica: Resumir como pseudocódigo/esquema: Crea un esquema en forma de comentarios HTML describiendo cómo debo estructurar visualmente el <header>, <main> y <footer> de una página de aterrizaje (landing page) típica.
  • ✅ Buena práctica: Pedir una analogía o metáfora: Explica el concepto de Especificidad (Specificity) en las clases y selectores de CSS usando una analogía sencilla.

Dividir tareas en pasos más pequeños

❌ Evita: Prompts muy largos con muchas instrucciones visuales al mismo tiempo:

Ayúdame a maquetar todo mi sitio web de portafolio. Debe tener una barra de navegación fija en la parte superior, una sección hero con una imagen de fondo oscurecida y un texto centrado. Debajo de eso, necesito una grilla de 3 columnas para mostrar mis proyectos, donde cada tarjeta se eleve al pasar el mouse, y al final un pie de página negro con íconos sociales blancos que giren...

✅ Haz lo siguiente: Dividir el proyecto de maquetación en subtareas lógicas, usando listas numeradas:

Ayúdame a construir la estructura y el diseño de mi portafolio web. Vamos a hacerlo paso a paso. Para empezar, asegúrate de cumplir con estos requisitos iniciales:

  1. Genera el marcado HTML semántico únicamente para la barra de navegación (header) y la sección principal de bienvenida (hero).
  2. Proporciona el CSS necesario para que la barra de navegación use Flexbox para espaciar el logotipo a la izquierda y los enlaces a la derecha.

Optimizar Prompts

  1. Pedir a ChatGPT que haga preguntas aclaratorias sobre un prompt amplio:

    Voy a darte un prompt y quiero que me hagas preguntas aclaratorias para ayudarme a optimizarlo. Luego, sugiéreme un prompt más efectivo basado en mis respuestas. El prompt inicial es: "Por favor, dame el código HTML y CSS para hacer un menú de navegación responsivo (tipo hamburguesa) para móviles."

  2. Responde las preguntas aclaratorias de ChatGPT.
  3. Cuando ChatGPT devuelva un prompt optimizado, vuelve a ingresarlo a ChatGPT.
  4. ¡Éxito!

Prompts basados en roles

✅ Buena práctica: Actúa como un...

  • ...diseñador UI/UX experto y ayúdame a definir una paleta de colores coherente y contrastante para mi página.
  • ...desarrollador Front End senior y recomiéndame la mejor forma de organizar mis archivos de estilos CSS.
  • ...especialista en accesibilidad web y revisa mi código HTML para asegurar que los lectores de pantalla puedan interpretarlo correctamente.

Prompts con Ejemplos

✅ Buena práctica:

Por favor, escribe una regla CSS para crear un botón moderno con una sombra sutil (box-shadow) y bordes redondeados, utilizando los siguientes valores como guía visual:

Color de fondo: #087ea4
Radio del borde: 8px
Desplazamiento de la sombra: 4px hacia abajo, color negro con 20% de opacidad

✅ Buena práctica:

Por favor, genera la estructura HTML para una lista de proyectos de diseño. Utiliza la etiqueta <ul> y <li>. Cada ítem de la lista debe estar envuelto en una etiqueta <article> e incluir la siguiente información etiquetada correctamente:

  • Título del proyecto (como un h3)
  • Breve descripción del trabajo (como un párrafo)
  • Herramienta utilizada (por ejemplo: Figma, Illustrator)
  • Enlace al prototipo interactivo
